# Dependency Conventions

Before adding a dependency:

1. Check whether the project already includes an equivalent capability.
2. Check whether the standard library or framework already solves the problem cleanly.
3. Prefer established and actively maintained packages.
4. Avoid dependencies for trivial functionality.
5. Evaluate security and maintenance impact.

- Do not add duplicate libraries that solve the same concern without a clear reason.
- Remove unused dependencies.
- Keep versions controlled by the project's existing dependency-management strategy.
