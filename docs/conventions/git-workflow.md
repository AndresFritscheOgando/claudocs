# Git Workflow Conventions

- Keep the primary branch deployable.
- Use focused branches for feature, fix, refactor, or infrastructure work according to the repository's established process.
- Do not force-push shared branches.
- Do not rewrite shared history unless explicitly required and understood.
- Follow the repository's established merge or rebase strategy.
- Keep unrelated work separate.
- AI agents must not stage, commit, push, rebase, reset, or rewrite history unless explicitly instructed.
